# Project Demo & Starter Template

> **Note:** Currently, these are demo files. We'll be building out this project together!

---

## 📌 Getting Started

You can clone this repository to your local system and build your own version, or fork it to work on your own copy:

- **Clone:** Clone this repo locally and build your own version.
- **Fork:** Fork the repository on GitHub to maintain your own separate copy.

> 💡 **Reference:** Check [`Resources.md`](Resources.md) for the design guidelines and tech stack reference. If you have better design ideas, feel free to use them!

---

## 🚀 Step-by-Step Guide

### Step 1: Set Up Your AI Assistant / IDE

1. **Free / Trial Setup:**
   - Claim your Google Gemini plan (e.g., via the MyJio app offer if available).
   - Download and install [Antigravity IDE](https://edgedl.me.gvt1.com/edgedl/release2/j0qc3/antigravity/stable/2.5.5-4923483625488384/windows-x64/Antigravity%20IDE.exe).

2. **Alternative Tools:**
   - You can also use tools like **GitHub Copilot**, **Kilo Code**, or any other tool of your choice.
   - Choose whichever tool fits your preference and workflow.

---

### Step 2: Familiarize Yourself with the Tool

- Watch a quick walkthrough on YouTube if you are new to the tool.
- If you're using **Antigravity**, the interface is very straightforward and interactive (even easier than ChatGPT).

---

### Step 3: Load the Project with Context

- Clone this repo or provide the repository URL to your AI tool.
- Tag the [`Resources.md`](Resources.md) file (for example, `@Resources.md`) in your prompts so the AI understands the tech stack, structure, and design patterns.

---

### Step 4: Start Building

- Begin creating your own custom version!
- Iterate on the design, add features, and customize it to your liking.
